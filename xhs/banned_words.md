## 一、三类最容易踩的雷（按危险程度排序）

### P0-1 站外引流词（最致命，直接屏蔽不通知）
微信 / 加V / 私信我 / 公众号 / 二维码 / 扫码 / 加群 / QQ / 手机号 / 联系方式 /
淘宝 / 京东 / 抖音 / 快手 / 链接 / 网址 / 站外 / 导流 / 留资 / 加好友

**替代说法**：评论区交流 / 评论区扣 1 / 主页合集里翻 / 我整理在评论区置顶

### P0-2 绝对化承诺（广告法 + 平台双重打击）
保证 / 一定 / 必然 / 必然能 / 肯定能 / 100% / 百分百 / 绝对 / 永久 / 万能 /
零风险 / 包你 / 包会 / 包过 / 彻底解决 / 完全解决 / 一劳永逸

**替代说法**：更大概率 / 通常 / 多数情况下 / 相对更稳 / 有机会

### P0-3 极限词（广告法明令禁止）
最好 / 最佳 / 最优 / 最强 / 最省 / 最低 / 最便宜 / 第一 / No.1 / NO.1 /
排名第一 / 顶级 / 顶尖 / 极品 / 极致 / 无敌 / 世界级 / 国家级 / 全网 / 全行业 / 史无前例

**替代说法**：更靠前 / 相对更优 / 头部 / 常见做法 / 我实测下来更稳

### P0-4 刻意模糊化品牌名（9/4 新增，**反直觉雷区**）

> **不要为了"规避审查"而把品牌名拼错**——这是更严重的违规。
> 小红书审查系统对"形似品牌名但故意拼错"的模式高度敏感（拼音首字母、同音字、形近字替换），
> 这是软广/割韭菜/规避审查号的典型操作，识别后**直接限流进低质账号池**，比直接用品牌名危险 10 倍。

❌ BaiD / 百度（拼音首字母）
❌ 豆x / 豆 包 / 豆-b（形近拆分）
❌ DsspSxxx / Dssp（DeepSeek 形变）
❌ 文 X 一言 / 文X一言（文心一言 形近）
❌ 元-b / 元（宝字替换）
❌ 微 X / WX（微信 形近）
✅ 正常写全名：百度 / 豆包 / DeepSeek / 元宝 / 文心一言 / Kimi / ChatGPT

**品牌名正常提及是允许的**（见下文「允许正常使用」），不要自作聪明去模糊化。

### P0-5 承诺未来行为 / 诱导关注（9/4 新增）

> "我明天发结果" / "下篇讲 X" / "下周公布" 这类**博主自己承诺未来行为**的表述，
> 触发"诱导关注"逻辑——审查模型会认为你在用未来内容换关注。**比承诺数据更危险**。

❌ 明天发 / 明天公布 / 明天给 / 明天更新
❌ 下篇讲 / 下篇出 / 下篇说
❌ 下周出 / 下周更新 / 下周公布
❌ 即将发布 / 即将上线
❌ 关注我看后续 / 关注后看续集

**替代说法**：
- 「这次先讲到这，下一篇会换一个角度接着拆」（陈述事实，不承诺具体时间）
- 「把这个话题先记着，下回聊」（模糊化预告）
- 留个钩子但**不承诺交付时间**

### P0-6 焦虑营销 / 宿命论语气（9/4 新增）

> 用"不存在 / 死 / 消失 / 淘汰"等**宿命论+重复**的句式制造焦虑，
> 触发"焦虑营销"标签，比纯情绪化严重得多。

❌ 重复使用「不存在 / 死 / 消失 / 淘汰」（同篇出现 2 次以上）
❌ 「AI 里搜不到你 = 你不存在」类数学等式
❌ 「不做 X 就会被淘汰」类二元对立宿命论
❌ 「不改变就死」类恐慌营销

**替代说法**：
- 「容易被 AI 漏掉」→「AI 给出的答案里很少提到」
- 「不进答案就没人看到」→「客户在 AI 里问到这类问题时找不到你」
- 用「容易被忽略 / 难被发现 / 缺少被引用的入口」等具体描述代替「不存在」

## 二、P1 建议规避（不影响过审，但压推荐）

数据承诺：暴涨 / 翻倍 / 爆单 / 10万+ / 月入过万 / 日入 / 躺赚 / 稳赚 / 暴富 /
被动收入 / 零成本 / 免费送 / 免费领 / 限时 / 秒杀 / 清仓 / 包邮

诱导互动（条件式）：点赞过 X 就 / 收藏过 X 就 / 转发才能 / 不点赞就

夸张形容：神器 / 黑科技 / 绝了 / 逆天 / 封神 / 王炸 / 杀手锏 / 秒杀一切

## 三、允许正常使用（不用自己吓自己）

- 引导互动：欢迎评论区交流 / 评论区扣 1 / 报上你的行业 / 关注我，这些都是平台鼓励的
- 口语化表达：贼好使 / 我踩过的坑 / 说实话
- **品牌名**（这是重点！）：**百度 / 豆包 / DeepSeek / 元宝 / 文心一言 / Kimi / ChatGPT / 知乎 / 抖音 / 微信——正常提及就行，不要模糊化**。
  把品牌名写清楚不会被判违规，反而能获得更精准的搜索流量；模糊化是更严重的雷。
- 数据用「量级 + 趋势」：被引用次数明显变多 / 从个位数涨到几十，不用精确承诺
- 引用他人的话：✅ 「用户说：xxx」、✅ 「老板问：xxx」（正常叙事，不算宣传）

## 四、发布前自检清单

1. 跑一遍 `python3 xhs/check_words.py`，**P0 必须为 0**
2. 标题里不出现绝对化词（标题权重最高，最容易被判）
3. 正文里不出现任何站外平台名和联系方式
4. 标签里不出现引流词（#引流 #私域 #加微信 这类一定删）
5. 首图文字同标准检查（图片 OCR 也过审）
6. **品牌名一律写全名**（百度 / 豆包 / DeepSeek / 元宝 / 文心一言），不要拼音首字母、不要形近拆分
7. **结尾别承诺时间**：「明天发 / 下篇讲 / 下周出」一律改成「下一篇换一个角度接着拆」这类陈述
8. **同篇"不存在/死/消失"最多出现 1 次**（重复触发焦虑营销）
