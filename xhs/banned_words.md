## 一、三类最容易踩的雷（按危险程度排序）

### P0-1 站外引流词（最致命，直接屏蔽不通知）
微信 / 加V / 私信我 / 公众号 / 二维码 / 扫码 / 加群 / QQ / 手机号 / 联系方式 /
淘宝 / 京东 / 抖音 / 快手 / 链接 / 网址 / 站外 / 导流 / 留资 / 加好友

**替代说法**：评论区交流 / 评论区扣 1 / 主页合集里翻 / 我整理在评论区置顶

### P0-2 绝对化承诺（广告法 + 平台双重打击）
保证 / 一定 / 必然 / 必然能 / 肯定能 / 100% / 百分百 / 绝对 / 永久 / 万能 /
零风险 / 包你 / 包会 / 包过 / 彻底解决 / 完全解决 / 一劳永逸

**替代说法**：更大概率 / 通常 / 多数情况下 / 相对更稳 / 有机会

### P0-3 极限词（广告法明令禁止）

排名第一 / 顶级 / 顶尖 / 极品 / 极致 / 无敌 / 世界级 / 国家级 / 全网 / 全行业 / 史无前例

**替代说法**：更靠前 / 相对更优 / 头部 / 常见做法 / 我实测下来更稳

## 三、允许正常使用（不用自己吓自己）

- 引导互动：欢迎评论区交流 / 评论区扣 1 / 报上你的行业 / 关注我，这些都是平台鼓励的
- 口语化表达：贼好使 / 我踩过的坑 / 说实话
- 品牌名：豆包 / DeepSeek / 元宝 / 文心一言 / 知乎 / 百度（正常提及，别放外链）
- 数据用「量级 + 趋势」：被引用次数明显变多 / 从个位数涨到几十，不用精确承诺
