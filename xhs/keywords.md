# 小红书搜索流量 · 关键词库（2026-09-20 建立）

> 背景：旺仔 09-20 反馈「曝光低的原因之一是少了小红书的搜索流量——标题和内容里
> **没有可被搜索的词汇**」。这篇、以及之后每一篇，都要先定搜索词再写正文。
>
> 搜索流量是唯一能长期沉淀的免费流量：笔记发完几个月还会被搜到，
> 转化效率比推荐流高。推荐流来得快去得也快，搜索是长期活水。

## 一、核心规则（每篇必做，写正文前先定词）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **一篇只埋 1 个核心词 + 3 个长尾词** | 词多了权重分散，系统判断不出你这篇在讲什么 |
| 2 | **标题前 20 字必须出现核心词** | 标题是搜索权重最高的位置，前 20 字尤其重 |
| 3 | **正文前 100 字自然融入核心词 + 1–2 个长尾词** | 摘要区权重仅次于标题 |
| 4 | **四维布局**：标题 / 正文首段 / 话题标签 / 置顶评论 | 四处在讲同一件事，系统才好打标收录 |
| 5 | **核心词全文出现 2–4 次，禁止堆砌** | 堆砌会触发隐形限流；读出来顺嘴才算合格 |
| 6 | **长尾词用「人群 + 场景 + 痛点」**，别抢大词 | 「AI 搜索」这种大词抢不过，长尾词才是新号的机会 |
| 7 | **置顶评论再补一次核心词** | 搜索会抓评论；用自己口吻补，不要复制标题 |
| 8 | **合集名也带核心词** | 合集是搜索入口之一 |

**自检一句**：把笔记里所有「我 / 我们 / 这个 / 它」代词遮掉，
还能不能看出这篇在讲什么？看不出就是没埋对词。
